What this report measures

Every study recorded with a Polar H10 chest strap is evaluated for signal quality using two layers:

1. Binary flag (MARKED_BAD_POLAR) — a per-study yes/no flag set when HR data is deemed unreliable.
2. Signal loss % (per-second HR data) — actual percentage where the Polar reported HR=0, frozen HR, or extreme artifacts.

Why these numbers differ

Algorithmic detection catches measurable failures — HR=0 dropout, frozen values, extreme artifacts. Fleet average: 1.46%.
Lab assessment (binary flag) also captures plausible-but-wrong HR (e.g. 90 BPM when true HR is 150). Fleet rate: 14.9%.
The gap means the binary flag is catching what algorithms can’t — that’s its job.
